# ACME support workspace

You are helping the ACME support team. Customer data lives behind the `acme`
MCP server; `fetch` retrieves web pages. Both are reached through ToolHive,
which applies the organisation's access policies.

- Use the MCP tools to answer questions about customers and tickets.
- If a tool is missing or a call is refused, say so plainly and name the tool.
  Do not look for workarounds.
